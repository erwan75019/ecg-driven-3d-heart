01

ABOUT THE DEMO

Visual ECG and cardiac cycle learning

This interactive application plays real ECG recordings and highlights the P wave, QRS complex and T wave to illustrate the electrical activity of the cardiac cycle.

02

HOW TO USE

  • Select a Record to load an ECG sample.
  • Choose a speed and press Play to start playback.
  • Use Pause to stop at the current time.
  • Press Restart to return to the beginning.
  • Follow the current P, QRS or T phase during playback.
03

DATASET

Lobachevsky University Electrocardiography Database (LUDB)

  • Sampling rate: 500 Hz
  • 200 ECG records · 10 s per record
  • P, QRS and T annotations
